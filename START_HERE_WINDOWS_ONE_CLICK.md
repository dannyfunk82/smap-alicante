# SMAP Web 1.0 — avvio rapido Windows

## Requisiti

- Node.js LTS installato;
- PostgreSQL installato e in esecuzione;
- progetto estratto in una cartella locale, per esempio `C:\dev\smap_web_sprint17`.

## Primo utilizzo

1. Copia `.env.local` dalla versione precedente oppure lascia che lo script crei il modello.
2. Doppio clic su `windows\SETUP_AND_START_SMAP.cmd`.

In alternativa usa `windows\SMAP_CONTROL.cmd` per accedere al menu completo.
