# SMAP Web Sprint 15

## Goal

Close the MVP delivery cycle with operational continuity, measurable service objectives and repeatable incident learning.

## Delivered

- configurable SLOs and measurements;
- continuity score and recommendation;
- on-call rota;
- backup, failover, incident and communications exercises;
- incident postmortems and corrective actions;
- Markdown continuity report;
- continuity checks in preflight;
- backup coverage for all new tables;
- four additional automated tests.

## Demo path

1. Sign in as the demo administrator.
2. Open **Continuidad / Continuity**.
3. Record a new API latency measurement.
4. Change an SLO threshold.
5. Schedule an on-call shift.
6. Complete the backup restore exercise.
7. Open or publish a postmortem.
8. Export the continuity report.
