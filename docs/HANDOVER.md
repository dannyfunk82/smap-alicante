# SMAP 1.0 — Handover

Il pacchetto di handover trasferisce applicazione, database, procedure e responsabilità al team che gestirà SMAP.

## Contenuti minimi

- codice sorgente e storico delle migrazioni;
- configurazioni di esempio senza segreti;
- catalogo API e dizionario dati;
- procedure di installazione, backup, ripristino e rollback;
- controlli di sicurezza, privacy e accessibilità;
- runbook, contatti di escalation e continuità operativa;
- prova di accettazione con risultato registrato.

## Processo

1. Aggiornare la checklist nella sezione **Entrega / Handover**.
2. Associare un responsabile e un’evidenza a ogni controllo obbligatorio.
3. Revisionare e approvare i documenti.
4. Eseguire `npm.cmd run acceptance`.
5. Registrare una prova di accettazione nell’interfaccia.
6. Esportare il rapporto Markdown e conservarlo con il verbale di consegna.
