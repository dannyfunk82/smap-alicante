# SMAP Web 1.0.0

Questa versione consolida quindici incrementi funzionali in un rilascio di handover.

Comprende mobilità simulata, biglietteria demo, accessibilità, sicurezza, integrazioni, pilot, privacy, governance, release, continuità e accettazione finale.

La rete, i prezzi e la telemetria inclusi sono dimostrativi. Prima di un servizio reale devono essere validati contratti, feed AVANZA, pagamenti, requisiti legali, DPIA, accessibilità e procedure operative.
