# Web Sprint 2

## Consegnato

- dashboard senza sezioni segnaposto;
- telemetria demo calcolata lato server, senza processo in background;
- polling client ogni 5 secondi;
- mappa schematica e supporto Google Maps opzionale;
- ricerca locale sulla rete caricata;
- preferiti persistenti;
- biglietteria simulata con tariffazione per tratta;
- QR SVG firmato;
- profilo e accessibilità;
- gestione robusta delle risposte API non JSON.

## Limiti intenzionali

- il movimento degli autobus è simulato;
- non sono considerati traffico, ritardi e deviazioni;
- il pagamento non produce addebiti;
- il QR è verificabile strutturalmente ma non è collegato a validatrici AVANZA reali;
- le notifiche push saranno aggiunte in un incremento successivo.
