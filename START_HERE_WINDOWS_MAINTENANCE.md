# SMAP Windows maintenance quick start

Open:

```text
windows\SMAP_CONTROL.cmd
```

New maintenance options:

```text
10. Diagnostica e pacchetto supporto
11. Riparazione sicura
12. Controllo integrità dati
13. Aggiorna da pacchetto ZIP
```

Direct launchers:

- `windows\DIAGNOSE_SMAP.cmd`
- `windows\REPAIR_SMAP.cmd`
- `windows\UPDATE_SMAP.cmd`

Read `docs\LONG_TERM_MAINTENANCE.md` before performing an update or repair.
